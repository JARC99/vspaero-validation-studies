# vspaero-validation-studies
 
This repository contains the Python scripts used to execute the VLM analyses described in the research article titled [_Validation of VSPAERO for Basic Wing Simulation_](https://www.scipedia.com/public/Rosas-Cordova_et_al_2024a) published in the _Revista Internacional de Métodos Numéricos para Cálculo y Diseño en Ingeniería_ in November of 2024.
